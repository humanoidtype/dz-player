# Dz Player - System Architecture

**Version:** 0.3.0 (Updated: 2026-08-21)
**Stack Final:** React + Vite (Frontend) + Express (Backend) + Capacitor JS (APK WebView)
**Principles:** Clean Architecture + Feature-Sliced, Monorepo `client/` + `server/`

---

## 1. High-Level Overview

```
┌──────────────────────────────────┐     ┌──────────────────────────┐
│  Client: React + Vite            │     │  Server: Express (Node)  │
│  Dashboard | Player | Search     │◄───►│  /api/youtube/*          │
│  Sidebar | MiniPlayer persistent │     │  /api/auth/*             │
│  Zustand + TanStack Query        │     │  /api/download/*         │
│  Capacitor WebView (APK)         │     │  youtubei.js (browsing)  │
└──────────────┬───────────────────┘     │  yt-dlp (stream/dl)      │
               │                         │  Auth Google OAuth PKCE  │
               │ Local                   └──────────┬───────────────┘
               │ IndexedDB/Dexie                    │
               │ MediaStore (via Capacitor)          │ YouTube (Innertube)
               └────────────────────────────────────┘
```

- **Frontend (React)** handle UI 1:1 mockup, player HTML5, queue, offline cache.
- **Backend (Express)** proxy YouTube: `youtubei.js` untuk browsing (trending, search, suggest, playlist), `yt-dlp` untuk stream resolve + download. Cookies Google di-inject ke semua request YouTube.
- **Capacitor** wrap Vite build (`dist/`) jadi WebView APK.

## 4. Core Modules

### 4.1 Player Engine (Frontend)
```ts
interface PlayerEngine {
  load(media: Media): Promise<void>
  play(): void; pause(): void; seek(sec: number): void
  setQueue(list: Media[], idx: number): void
  onProgress(cb: (pos: number, dur: number) => void): void
  onEnded(cb: () => void): void
}
```
Impl: `HtmlPlayer` (hls.js). Sebelum `load()`, engine cek `streamUrlExpiresAt` — jika expired, re-fetch via `POST /api/youtube/stream/:id`.

### 4.2 Auth & Cookie Manager (OAuth PKCE Flow)

```
[Frontend]
  Google Sign-In (OAuth PKCE)
  → dapat id_token + access_token
  → POST /api/auth/google { idToken, accessToken }

[Server]
  → validate id_token via Google certs
  → init youtubei.js dengan OAuth credentials
  → youtubei.js generate YouTube session cookies
  → encrypt cookies AES-GCM (YOUTUBE_COOKIES_ENCRYPT_KEY)
  → simpan di auth.db session table
  → return { sessionId, user }

[Frontend]
  → simpan sessionId di Capacitor SecureStorage
  → semua request: Authorization: Bearer <sessionId>
  → cookies TIDAK PERNAH expose ke frontend
```

**Refresh flow:**
```
YouTube 429 / bot challenge
  → Express cek refreshToken
  → valid: re-init youtubei.js → update cookies auth.db → retry
  → invalid: return 401 BOT_DETECTED → frontend toast + prompt re-login
```

**Guest mode:**
- Direct request ke YouTube tanpa cookies
- Exponential backoff retry jika 429
- Warning banner di UI

### 4.3 YouTube Service Split (Express)

**youtubei.js** → browsing:
- `GET /api/youtube/trending` — homepage feed
- `GET /api/youtube/search` — search results
- `GET /api/youtube/suggest` — live recommendations
- `GET /api/youtube/playlist` — My Library (read-only)

**yt-dlp** → stream + download:
- `POST /api/youtube/stream/:id` — resolve streamUrl
- `GET /api/download/:id` — download file

**yt-dlp cache strategy:**
```
POST /api/youtube/stream/:id
  → check yt_cache (key: "stream:{id}:{quality}")
  → hit && expiresAt > now: return cached streamUrl
  → miss: spawn yt-dlp → parse streamUrl → cache TTL 5h → return
```
TTL 5h aman sebelum YouTube expire ~6h.

**Memory cache:** LRU 5m untuk trending/search (tidak cache personal My Library).

### 4.4 streamUrl TTL (Frontend)
- `Media.streamUrlExpiresAt` (epoch ms, ~5h dari fetch time)
- Player engine: sebelum play, `if (Date.now() > media.streamUrlExpiresAt) → re-fetch stream`
- Dexie update `streamUrl` + `streamUrlExpiresAt` setelah re-fetch

### 4.5 Rewind & Downloads (Frontend Local)
- `history` + `media` Dexie. Rewind read dari `history` join `media`.
- Download: frontend minta `/api/download/:id` → server stream/proxy → Capacitor Filesystem save → catat di `download` table.

## 10. CI/CD (GitHub Actions)

```yaml
name: ci
on: { push: { branches: [main, dev] }, pull_request: {} }
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - run: npm ci
      - run: npm run lint && npm run typecheck && npm test --workspaces
      - run: npm run build
  build-apk:
    needs: check
    if: github.ref == 'refs/heads/main'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - uses: actions/setup-java@v4  # JDK17
      - run: npm ci && npm run build
      - run: npx cap sync android
      - run: cd android && ./gradlew assembleDebug
      - uses: actions/upload-artifact@v4
        with: { name: dz-player-apk, path: android/app/build/outputs/apk/debug/*.apk }
  release:
    needs: build-apk
    steps:
      - uses: softprops/action-gh-release@v1
        with: { files: "*.apk", tag_name: "v0.1.${{ github.run_number }}-beta" }
```

## 11. Offline & Security

- Image cache LRU 500MB via `CacheStorage` + Dexie
- Cookies encrypted AES-GCM server-side, tidak pernah ke frontend
- sessionId di Capacitor SecureStorage (client)
- Express: helmet + cors whitelist (`https://dzplayer.dzfee.id`, `capacitor://localhost`)
- Rate-limit `/api/auth/*`
- Tidak ada cleartext HTTP

## 12. ADR (Architecture Decision Records)

| ADR | Decision | Reason |
|-----|----------|--------|
| 001 | React + Vite (not Next) | SPA ringan, Capacitor WebView paling cocok |
| 002 | Express backend | Butuh persistent cookies & yt-dlp, VPS pull deploy |
| 003 | Capacitor JS (not Cordova) | Modern, PWA compatible, plugin ecosystem |
| 004 | Zustand + TanStack Query | Global simple + server cache |
| 005 | hls.js untuk streaming | Support m3u8 di Web, fallback ke mp4 |
| 006 | GitHub CI + VPS pull | Automate build APK + deploy, tidak build di Termux |
| 007 | Hybrid youtubei.js + yt-dlp | youtubei.js: browsing (clean API), yt-dlp: stream/download (paling stabil). yt-dlp cache TTL 5h di yt_cache |
| 008 | OAuth PKCE flow | id_token → server exchange cookies via youtubei.js → sessionId ke client. Cookies tidak pernah expose ke frontend |
| 009 | My Library read-only Phase 1 | Tidak perlu YouTube Data API v3 write scope, lebih simple & aman |
| 010 | Guest: direct + backoff | Proxy Phase 3. Guest second-class, warning UI sudah ada |
| 011 | Tailwind v4 | @theme directive, dynamic dark/light via CSS media query, tidak perlu JS toggle |
| 012 | Monorepo client/ + server/ | client/ (React), server/ (Express), root workspaces: ["client","server"] |
| 013 | Background playback Phase 2 | @capacitor-community/background-runner, full JS, tidak perlu custom native plugin |
